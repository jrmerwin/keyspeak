Particles never change. Every other word is a verb, a noun or a modifier; its first letter moves to the back, then the ending depends on what it lands next to.

Verbs

starts with a vowel
rest + v + the vowel + bus
eat → atvebus · open → penvobus
starts with a consonant, rest starts with a vowel
rest + the consonant + or
run → unror · go → ogor · want → antwor
starts with a consonant, rest starts with a consonant
rest + the consonant + um
fly → lyfum · stop → topsum · bring → ringbum

Nouns

starts with a vowel
rest + k + the vowel
arrow → rrowka · apple → ppleka · egg → ggke
starts with a consonant, rest starts with a vowel
rest + the consonant + i
book → ookbi · milk → ilkmi · river → iverri
starts with a consonant, rest starts with a consonant
rest + the consonant + ar
broom → roombar · store → toresar · bread → readbar

Modifiers (adjectives, adverbs)

starts with a consonant
rest + the consonant + ig
quick → uickqig · cold → oldcig · really → eallyrig
starts with a vowel
rest + the vowel + ig
open → penoig · easy → asyeig

The app guesses each word's class from a small dictionary and from the particle before it. When it guesses wrong, tap the word in the translation to cycle verb → noun → modifier; the app remembers your choice for that word.
